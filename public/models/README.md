# 3D models

## `human-body.glb`

- **Source:** [bhagyeshsave/human-3d-body](https://github.com/bhagyeshsave/human-3d-body) (`client/public/geometries/human_body.glb`)
- **Usage:** Athlete performance hologram on `/athletes/[slug]`
- **Note:** Male and female athlete profiles both use this model. Female profiles render with a light blue hologram tint (`#6eb5ff`); male profiles use orange (`#ff5a1f`).
